# 🎧 Spotify 2023 — Tableau Data Analysis

An interactive **Tableau data analytics project** exploring Spotify's 2023 most-streamed songs through visualisation, comparison, and exploratory analysis.

The project investigates the relationship between **streaming performance, audio characteristics, artists, platform exposure, release trends, and cross-platform reach**.

## 📊 What This Project Covers

- 🎵 **Music DNA** — Analysis of audio characteristics and top-streamed songs
- 📱 **Platform Wars** — Comparison of platform exposure and streaming performance
- 🎤 **Artist Impact** — Artist performance and solo vs. collaboration analysis
- 📈 **Music Through Time** — Release and streaming trends over time
- 🌐 **Cross-Platform Reach** — Comparison of song presence across platforms
- 📌 **Spotify 2023 Insights** — Consolidated dashboard highlighting key findings

## 🛠️ Tools Used

- **Tableau** — Data visualisation, dashboarding and exploratory analysis
- **Microsoft Excel** — Dataset source and initial data handling

## 🎯 Objective

The goal of this project is to transform raw Spotify data into an **interactive visual analytics solution** that makes patterns in music streaming easier to explore and understand.

## 📁 Project Contents

- `Spotify_2023.xlsx` — Source dataset
- Tableau workbook / dashboards
- Dashboard screenshots
- Analytical report

## 🔍 Key Analytical Areas

The project explores:

**Streaming Performance • Audio Features • Artists • Collaborations • Platform Exposure • Release Trends • Cross-Platform Presence**

This project was developed as part of a **Tableau data analytics coursework**.
